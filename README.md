# Portfólio Acadêmico — Thiago Wyse

Repositório de projetos desenvolvidos por **Thiago Wyse** durante a graduação em **Ciência da Computação**. Este portfólio apresenta minha evolução técnica, minha capacidade de modelar problemas e a aplicação prática de conceitos estudados no curso.

## Projetos

| Projeto | Descrição | Disciplina | Tecnologias | Código e documentação |
| --- | --- | --- | --- | --- |
| Polynomial Linked List | Aplicação de terminal que representa e manipula polinômios com uma lista simplesmente encadeada. | Estruturas de Dados | Java | [Ver projeto](projects/polynomial-linked-list/) |

## Competências demonstradas

- implementação de estruturas de dados encadeadas;
- modelagem com tipos abstratos de dados e orientação a objetos;
- algoritmos para inserção, busca, remoção e percurso de listas;
- composição de operações algébricas sobre estruturas dinâmicas;
- validação de entradas em aplicações de terminal;
- criação de testes sem dependências externas;
- organização e documentação de código Java.

## Como executar os projetos

Cada diretório em `projects/` contém instruções próprias de compilação, execução e teste. O projeto atual requer apenas um JDK e não possui dependências externas.

Consulte o [README do Polynomial Linked List](projects/polynomial-linked-list/README.md) para o passo a passo completo.

## Sobre este portfólio

Os projetos foram desenvolvidos durante a graduação em Ciência da Computação. A documentação e a organização foram aprimoradas para facilitar a análise técnica, preservando o código e o escopo acadêmico originais.
